# 📖 Project Overview

DIS-SMS (Data Insight School Management System) is an enterprise-grade web application developed to improve the management of schools by providing a centralized platform for administrators, teachers, students, accountants, and other stakeholders.

The system streamlines daily school operations including:

- Student Management
- Teacher Management
- Academic Administration
- Attendance Tracking
- Examination Management
- Result Processing
- Fee Management
- Payment Processing
- School Announcements
- Events Management
- Notifications
- Dashboard Analytics
- Audit Logging

The backend is built using a layered architecture with Express.js, Prisma ORM, and MySQL, making it secure, maintainable, and scalable.

# 🚀 Installation Guide

## Prerequisites

Before running the project, ensure the following software is installed:

- Node.js (v22 or later)
- npm
- MySQL Server 8.0+
- MySQL Workbench
- Git
- Visual Studio Code

---

# 📥 Clone the Repository

```bash
git clone https://github.com/your-username/DIS-SMS.git
```

Navigate to the project folder:

```bash
cd DIS-SMS
```

---

# 📦 Backend Installation

Navigate to the backend folder:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

---

# ⚙️ Environment Configuration

Create a `.env` file inside the `backend` folder.

Example configuration:

```env
# Application
NODE_ENV=development
PORT=5000
API_VERSION=v1

# Frontend
CLIENT_URL=http://localhost:5173

# School
SCHOOL_NAME=DIS-SMS

# Database
DATABASE_URL=mysql://root:yourpassword@localhost:3306/dissms

# Authentication
JWT_SECRET=your_super_secret_key
JWT_EXPIRES_IN=1d
```

> **Important:** Never commit your real `.env` file to GitHub.

---

# 🗄 Database Setup

Create a MySQL database named:

```sql
CREATE DATABASE dissms;
```

Validate the Prisma schema:

```bash
npm run prisma:validate
```

Generate the Prisma Client:

```bash
npm run prisma:generate
```

Create and apply migrations:

```bash
npm run prisma:migrate
```

Reset the development database (if needed):

```bash
npm run prisma:reset
```

Open Prisma Studio:

```bash
npm run prisma:studio
```

---

# ▶️ Running the Backend

Development mode:

```bash
npm run dev
```

Production mode:

```bash
npm start
```

The backend API will be available at:

```text
http://localhost:5000
```

| `npm run prisma:studio` | Open Prisma Studio |
| `npm run db:push` | Push Prisma schema directly to the database |
